## 1. 核心结论（三层一致）

### 1.1 真正的"激光钝化"文献极少

| 层 | A 类（激光诱导氧化）占该层比例 |
|---|---|
| L1（三重证据）| **5%**（4/79）|
| L2（激光∧电化学）| **2%**（4/207）|

**两层一致在 2–5%** → **"激光钝化"在文献中确实稀有**，不是筛选偏差。

### 1.2 约一半的"激光"文献只是成形手段

| 层 | F 类（成形/增材）占比 |
|---|---|
| L1 | 51% |
| L2 | **48%** |

**稳定在 ~50%** → **把 SLM/LPBF 成形件的耐蚀性当作"激光钝化效果"是本领域最常见的误读**。

## 2. 激光的真实角色（L1+L2 汇总）

| 角色 | 定义 | 能否作"激光钝化"证据 |
|---|---|---|
| **A 激光钝化** | **脉冲激光诱导表面氧化成膜** | ✅ **是**（约 9 篇）|
| B/B1 激光表面重熔 | LSM 熔凝（细化/去敏化/相溶解）| ⚠️ 相关但非钝化 |
| B2 激光表面热处理 | 相变硬化（未熔化）| ⚠️ 相关 |
| C 激光表面织构 | LST/LIPSS（形貌 + 氧化）| ⚠️ 部分 |
| D 激光冲击强化 | LSP（机械路径）| ❌ |
| E 激光熔覆 | 涂层沉积 | ❌ |
| **F 成形/增材制造** | SLM/LPBF/DED，激光只造件 | ❌（占 ~50%）|
| G 激光焊接 / H 无激光 | | ❌ |

### 2.1 真正激光钝化的共同特征（9 篇综合）

| 特征 | 内容 |
|---|---|
| 激光类型 | 纳秒（多数）/ 飞秒 / 强场脉冲 |
| 作用方式 | **诱导表面氧化成膜**，不烧蚀、不熔化或仅微熔 |
| 膜特征 | **Cr 富集氧化物**（Cr₂O₃ / FeCr₂O₄），10–20 nm |
| 性能收益 | **Epit 提升 0.2–1.2 V**；icorr 降 1–2 个数量级 |
| 工艺窗口 | **存在最优能量密度**（如 4.96–6.04 J/cm²），过量反而有害 |

## 3. 与常规钝化的对比（L3 的关键贡献）

| 工艺 | Epit 提升 | 出处 |
|---|---|---|
| **常规硝酸钝化** | 450–650 → 950–1150 mV（**+500**）| `1023_a_1004719213960`（L3）|
| **激光熔凝（B 类）** | 100 → 610 mV（**+510**）| `apsusc.2015.08.015`（L2）|
| **激光诱导氧化（A 类）** | 0.4 → **1.4 V**（**+1000**）| `optlastec.2026.116327`（L2）|

**结论**：**常规钝化 ≈ 激光熔凝**；**只有真正的激光诱导氧化明显更优**（+1000 mV）。

## 4. 钝化膜的科学参数库

### 4.1 Mott-Schottky（L3 贡献 56 篇）

**规律（比单点数值更有价值）**：

| 规律 | 定量证据 |
|---|---|
| **半导体类型随电位变化** | 四区 **p-n-p-n**（−0.50/0.20/0.60 V）；p→n（−0.5 V）|
| **N_D 随 pH 变化** | pH5 **0.393** → pH1 **2.335 ×10²¹ cm⁻³**（**↑6×**）|
| **N_D 随电位（解析式）** | **N_D = [0.85exp(−2.15U_f)+5.17]×10²⁰ cm⁻³** |
| **成分掺杂降低 N_D** | Si(IV)：**16.3→6.6 ×10²⁰**（↓2.5×）|
| **组织影响 N_D** | 奥氏体 / 铁素体 / 马氏体的 N_D/N_A 各不同 |
| **微生物/充氢提高 N_D** | 微生物 **0.94→4.41 ×10²¹**；充氢使 Cr₂O₃ 36→18% |

### 4.2 PDM 点缺陷模型（L3 贡献 16 篇）

| 参数 | 值 | 出处 |

## 6. 必须写入 skill 的边界声明（8 条）

1. **不得把 SLM/LPBF/DED 成形件的耐蚀性当作"激光钝化效果"**（约占一半文献）
2. **不得仅凭"激光处理后耐蚀性提升"就归因于激光钝化**（12+ 例真正原因是别的）
3. **不得忽略剂量上限**（8+ 例证明存在最优窗口，过量反而有害）
4. **不得忽略时间维度**（5+ 例短期改善但长期更差）
5. **跨文献比较 Epit 前必须做参比电极换算**（Hg/Hg₂SO₄ / SCE / Ag/AgCl / MSE 混用）
6. **Mott-Schottky 结论必须注明电位区间**（半导体类型随电位变化）
7. **膜厚必须注明测量方法**（XPS 溅射 1.8 nm vs TEM 直接观测 3–4 nm，差 2–3×）
8. **PDM 参数必须区分模型**（点缺陷模型 vs 溶解-扩散-沉积模型）

## 7. 方法学教训

1. **文本层与图像各有盲区，必须双路径交叉验证**
   - 文本层吞负号（`−153.0`→`\x00`）与指数（`10⁻²`→`10 2`）
   - 图像误读小字（`−0.080` 看似 `0.180`、`58.0` 看似 `62.9`）
2. **页选择上限会系统性漏判**"方法在前、结果在后"的论文（L2 救回 20+ 篇、L3 待补抽 72 篇）
3. **静默失败危险** —— 必须以产出文件判定覆盖，不能只看派发记录
4. **论文内部矛盾普遍存在**（4 例：符号 / 量级 / 数值 / 数值）
5. **"声称做但未见"存在**（2 例：摘要声称 M-S，正文无数据 / "planned"）
6. **假阳性激光有多种**（LIBS 作氢分析工具、fs-UV 激光用于 APT 蒸发、**LSCM 共聚焦显微镜**、引文中的 laser）
