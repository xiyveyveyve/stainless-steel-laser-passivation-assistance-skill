## 1. 任务与方法

L1 层（79 篇三重证据：激光∧电化学∧XPS）完成后，对候选池剩余文献做分层：

| **L2** | **激光∧电化学（无 XPS）** | **197（本报告）** |

| L4 | 仅电化学 | 349 |

**方法**：
- 每篇只渲染**摘要页 + 含表格/电化学内容的页**（上限 4 页）
- 子 agent 逐张 read_image 做**快速筛选**（判定激光角色 + 是否含电化学数值）
- 对"角色属 A/B1/B2/C 但所给页无数值"的篇目**补渲染结果页**并二次复核

**判定规则**：`worth_deep_dive = true` 当且仅当 **激光角色 ∈ {A, B1, B2, C}** 且 **图中有电化学数值**

## 5. 对 skill 的建议

### 5.1 证据分层

```
第 1 层（激光钝化直接证据）：L1 的 4 篇 + L2 的 4 篇 A 类 ≈ 8 篇
第 2 层（激光表面处理证据）：B/B1/B2/C 类 ≈ 46 篇（L1+L2）
第 3 层（机制证据）：次要队列 168 条 + L1 的 58 条
第 4 层（仅对照）：F/E/D/G/H 类
```

### 5.2 必须写入 skill 的边界声明

1. **不得把 SLM/LPBF/DED 成形件的耐蚀性当作"激光钝化效果"**（约占一半文献）
2. **不得仅凭"激光处理后耐蚀性提升"就归因于激光钝化** —— 已发现 12+ 例真正原因是粗糙度/力学状态/涂层相/氧化层/疏水化
3. **不得忽略剂量上限** —— 8+ 例证明存在最优窗口，过量反而有害
4. **不得忽略时间维度** —— 5+ 例证明短期指标改善但长期性能更差
5. **跨文献比较 Epit 前必须做参比电极换算**（Hg/Hg₂SO₄ / SCE / Ag/AgCl 混用）
6. **注意领域争议** —— 胞状结构、纳米 MnS 等问题的文献结论相互矛盾，不可当定论

## 6. 材料学教训（方法层面）

1. **文本层与图像各有盲区，必须双路径交叉验证**：
   - 文本层会吞负号（`−153.0` → `\x00 153.0`）与指数（`10⁻²` → `10 2`）
   - 图像会误读小字（`−0.080` 看似 `0.180`、`58.0` 看似 `62.9`）
   - **两者不一致时必须交叉核对**，不能单信一方
2. **页选择上限（4 页）对"方法在前、结果在后"的论文会系统性漏判** —— 本次通过补渲染救回 20+ 篇
3. **子 agent 并发限制（8）与深度限制（1）** 决定了只能靠主 agent 滚动调度
4. **静默失败危险**：多个子 agent 无产出无简报地失败，必须以**产出文件**判定覆盖
