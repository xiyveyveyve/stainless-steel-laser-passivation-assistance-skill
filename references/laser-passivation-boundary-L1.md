## 6. 对 skill 的具体建议

### 6.1 证据分层建议

```
第 1 层（直接证据，4 篇）：脉冲激光诱导氧化 → Epit/ND/EIS
第 2 层（部分证据，5 篇）：LSR / 织构化 + 化学修饰
第 3 层（对照，其余）：成形/机械/熔覆 —— 只能作「非激光钝化」对照
```

### 6.2 必须写入 skill 的边界声明

1. **不得把 SLM/LPBF/DED 成形件的耐蚀性当作「激光钝化效果」**（40 篇，占 51%）
2. **不得跨文献直接比较 Epit**：术语（Epit/Ebrk/Etp/二次钝化）与参比（SCE/Ag-AgCl/SHE）不一致
3. **不得忽略机制**：icorr 降低可能来自超疏水/硅烷/热处理，而非钝化膜
4. **剂量-效应非单调**：4 例证明存在最优窗口，过量反而有害

## 7. 方法与质量控制

- **逐张读图**（627+ 关键页 PNG），不使用文本层提取数值
- **三重陷阱防护**：负号丢失 / 波浪号误读 / 文本层吞指数（实测均命中）
- **自洽检验**：算术复现、物理合理性（Rct≮Rs、t=εε₀/C）、表头反算、倍数宣称复现
- **印刷缺陷照录 + flag**，不替作者改数
- **四层分离**：reported_observation / author_interpretation / derived_value / agent_inference
- **10 篇多路径独立提取**（交叉验证）
