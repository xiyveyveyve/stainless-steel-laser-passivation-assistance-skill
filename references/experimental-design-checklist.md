# 激光钝化实验最低设计要求（8 项）

> **用途**：在**设计**激光钝化实验时（以及评审他人实验设计时）核对。
> **来源**：每项要求都由本池实读的**反例**倒逼而来 —— 不是规范性建议，而是「不这么做就会得出错误结论」。
> **边界**：本文件是**领域规则**；DOE 生成与执行由外部工具承担。
> **自动核对**：`scripts/audit-experiment-design.py`

## 为什么需要这份清单

本池最反直觉的发现是：**激光处理对耐蚀性的改善不是单调的，也不是必然的**。三条决定性反例：

| 反例 | 量化结果 |
|---|---|
| **激光织构使点蚀电位下降 310 mV** | Ep **0.460 → 0.150 V**（Ag/AgCl）；改善实际来自 PFOTES 接枝 |
| **单纯提高 Cr 可致害** | 仅加 Cr 不加 N → Epit **222.4 → 19.8 mV**；Cr 偏析网络与基体构成电偶 |
| **剂量窗口下限** | 500 J/cm² LSR 反劣化至 **0.225 V**（低于未处理 0.344）；同剂量下 150 W 优于 300 W |

若不满足下面 8 项要求，实验**无法区分**「激光有效」与「激光无效甚至有害」。

---

## D1 · 必须有未处理对照（as-received）

| 项 | 内容 |
|---|---|
| **要求** | 每个材料状态至少包含 1 组 as-received（或同批同处理但不过激光）对照；对照组与激光组必须同批、同表面预处理、同测试日 |
| **依据** | `surfin.2024.104167` 激光织构使 Ep 从 0.460 降至 0.150 V；`surfcoat.2024.131598` 仅加 Cr 使 Epit 从 222.4 降至 19.8 mV |
| **缺失后果** | 无法区分「激光增益」与「样品批次/预处理差异」；改善可能来自抛光、清洗或接枝 |
| **验收** | 报告中出现 as-received / untreated / baseline 组的完整电化学数据 |

## D2 · 必须给剂量窗口（≥ 3 点）

| 项 | 内容 |
|---|---|
| **要求** | 至少 3 个激光剂量水平（能量密度或功率），其中至少 1 个低于最优值、1 个高于最优值；**不得只报单点「最优参数」** |
| **依据** | `apsusc.2013.09.086`：70% 搭接 → Epit **+340 mV**；90% 搭接 → **钝化区完全消失**；`electacta.2025.145913`：500 J/cm² 反劣化至低于未处理 |
| **缺失后果** | 单点无法证明「存在有效窗口」，也无法排除「更优剂量未被覆盖」或「该点恰在劣化区」 |
| **验收** | 剂量-响应表（≥3 行）+ 至少 1 个响应量（Epit / i_pass / R_ct）随剂量的趋势 |

## D3 · 必须声明 as-treated 与后处理态（含烧蚀层处置）

| 项 | 内容 |
|---|---|
| **要求** | 明确说明电化学/表面分析测的是 as-treated 表面还是后处理表面；若磨除/抛光，须给出**磨除深度与方式** |
| **依据** | `cja.2025.103799`：as-treated 生成 Cr₈O₂₁（表面 Cr 11.23→9.35 wt%）→ **Epit = −167 mV、无钝化平台**；**磨去 3.5 µm 烧蚀层后** Cr₂O₃ 52→71%、Rct 2.54×10⁶ Ω·cm² |
| **缺失后果** | 未熔烧蚀层可**反转结论**；as-treated 的结果不能被当作激光改性效果 |
| **验收** | Methods 中写明表面状态 + （若磨除）深度；表征中确认无残留氧化皮 |

## D4 · 能量密度与功率必须同时报告（不可互换）

| 项 | 内容 |
|---|---|
| **要求** | 引用剂量时同时给出：**功率、扫描速度、光斑尺寸、搭接率、道次、脉宽/频率、能量密度定义**（面平均 / 单脉冲峰值 / 累计） |
| **依据** | `electacta.2025.145913`：**同一能量密度 2000 J/cm² 下，150 W 优于 300 W**；`apsusc.2013.09.086`：正文「2.64×10⁷ W/cm²」是平均、图注「5.3×10⁷」是峰值 |
| **缺失后果** | 剂量不可复现、跨文献不可比；读者无法判断「同剂量不同结果」是物理差异还是定义差异 |
| **验收** | 参数表含全部上述字段 + 能量密度定义式 |

## D5 · 必须记录并控制保护气氛

| 项 | 内容 |
|---|---|
| **要求** | 记录激光处理时的气氛（空气 / Ar / N₂ / 水约束 / 真空）与流量；若对比气氛，须同剂量 |
| **依据** | `mi13071089`：**空气织构（FLAR）最差**（R_f 塌缩至 1.56×10⁻⁵ MΩ·cm²，浸后明显点蚀）；**氩气织构（FLAN）+ 热处理最优**（R_f 0.598 MΩ·cm²）。机理：Ar 抑制烧蚀区氧化 |
| **缺失后果** | 空气氧化层会主导结果；同一材料不同气氛可给出相反结论 |
| **验收** | Methods 写明气氛、流量、若用水约束写明水层厚度 |

## D6 · 独立样本重复数 n ≥ 4

| 项 | 内容 |
|---|---|
| **要求** | 每条件独立试样 n ≥ 4；报告误差棒类型（SD / SE / CI）与**采样单元**（独立试样 vs 同一试样内视场） |
| **依据** | **n=3 → 双侧最小 p = 2/C(6,3) = 0.100，结构上不可能 p<0.05**；本池大量文献报 n=3 却声称显著（如 `injury.2007.07.015` 的 Ti/Ti 4v3 报 p=0.027 而精确下限 0.0571）|
| **缺失后果** | 任何「A 优于 B」的声明在统计上不可建立；n=3 时秩检验最小可达 p=0.100 |
| **验收** | Methods 写明 n 与采样单元；图表有误差棒；组间比较有检验与 p 值 |

## D7 · 必须做长时浸泡验证（排除瞬态假象）

| 项 | 内容 |
|---|---|
| **要求** | 电化学评价至少包含一个 ≥ 24 h（推荐 ≥ 168 h）的浸泡时间点；对超疏水/织构表面必须给出浸泡后润湿性是否保持 |
| **依据** | `mi13071089`：超疏水（154°）**24 h 后完全失效**（→ 超亲水），其「耐蚀」是**滞留空气膜的瞬态假象**（R_f 仅 0.126 / 0.00562 MΩ·cm²）；而 `s41377-025-01952-5` 的强场光丝样品浸泡 **>6500 h** 仍保持 i_corr ~5.0×10⁻¹⁰ A/cm² |
| **缺失后果** | 短期数据会高估超疏水/多孔表面的耐蚀性；空气膜在真实服役中不持久 |
| **验收** | 报告含 ≥24 h 的 EIS/极化时间序列 + （若超疏水）浸泡后接触角 |

## D8 · 必须具备传统钝化对照

| 项 | 内容 |
|---|---|
| **要求** | 至少 1 组传统钝化对照（硝酸 / 柠檬酸 / 电解抛光 / 机械抛光），且与激光组同测试协议 |
| **依据** | `jmapro.2026.06.043`：Epit 原始 **0.205** → 化学钝化 **0.751** → 激光 **1.371 V**（激光确实优于化学钝化，差 0.620 V）；若没有化学钝化对照，就无法回答「激光是否比常规钝化更有优势」这个核心问题 |
| **缺失后果** | 只能证明「激光优于未处理」，不能证明「激光优于常规工艺」—— 而后者才是工程决策依据 |
| **验收** | 报告含传统钝化组的同协议数据 |

## 报告清单（Methods 必须包含的字段）

```
# 材料
grade / 实测成分(Cr,Ni,Mo,N wt.%) / 热处理 / 表面预处理 / 是否敏化

# 激光
波长 / 脉宽 / 频率 / 功率 / 光斑尺寸与形状 / 扫描速度 / 搭接率 / 道次 / 扫描策略
能量密度（含定义：面平均|单脉冲峰值|累计）/ 气氛与流量 / 入射角 / 是否水约束

# 表面状态
as-treated | 后处理（磨除深度/方式）| 粗糙度 Sa/Ra / 接触角

# 电化学
电解质成分与浓度 / 缓冲体系 / pH / 溶解氧或除氧方式 / 温度
参比电极（类型+内充液）/ 对电极 / 工作面积 cm² / 暴露面积几何
扫描速率 mV/s / 起止电位与判据 / EIS 频段-幅值-偏压点-等效电路
浸泡时长序列 / 重复数 n / 误差棒类型 / 采样单元

# 表面分析
XPS 结合能与分峰（含 C 1s 校准）/ 溅射速率与标样 / 膜厚（方法与标定）

# 对照
as-received / 传统钝化（硝酸|柠檬酸|电抛光|机械抛光）
```

## 最小可发表设计的三个模板

### 模板 A · 剂量筛选（回答「有没有效」）
```
材料：1 种，as-received 对照
激光：≥3 剂量点（含低于与高于候选最优值），固定其他参数
电化学：Epit + i_pass + EIS @ 1 h 与 24 h
判据：存在一个剂量使 Epit 显著高于 as-received（n≥4，p<0.05）
```

### 模板 B · 机制解析（回答「为什么有效」）
```
材料：1 种
激光：最优剂量 + 1 个劣化剂量（阴性对照）
表面分析：XPS 深度剖析 + TEM/AES 膜厚 + （可选）ToF-SIMS
电化学：Epit + i_pass + EIS + Mott-Schottky
判据：膜成分/厚度差异与电化学差异方向一致
```

### 模板 C · 工艺对比（回答「比常规钝化好吗」）
```
材料：1 种
处理组：as-received / 激光（最优剂量）/ 硝酸钝化 / 柠檬酸钝化 / 电抛光
电化学：同协议 Epit + EIS 长时（≥168 h）
判据：激光组在长时间点仍优于传统钝化组
```
